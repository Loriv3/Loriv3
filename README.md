## 🌐 Featured Networking Projects

### [MPLS L3VPN Backbone Lab](https://github.com/Loriv3/mpls-l3vpn-backbone-lab)

An ISP-style backbone built with **Containerlab and FRRouting**.

- **Underlay:** IS-IS Level 2
- **MPLS transport:** LDP label distribution and label switching
- **VPN services:** MP-BGP VPNv4, route reflector, per-customer VRFs, Route Distinguishers and Route Targets
- **Resilience:** redundant paths through a triangular core and BFD on core links
- **Validation:** pytest checks for routing/control-plane state and customer-site connectivity

The lab explores how two customers can use overlapping IP addressing while remaining separated by their VRFs. It is a learning environment, not a production network or a benchmark of measured failover times.

### [Network Design & Configuration Notes](https://github.com/Loriv3/Laboratory-Of-Network-Design-and-Configuration-Notes)

Study notes from Sapienza's *Laboratory of Network Design and Configuration* course, covering:

- IPv4 addressing, subnetting, routing and forwarding
- Dynamic routing fundamentals and OSPF
- Cisco IOS configuration and verification commands
- Ethernet, VLANs, inter-VLAN routing, DHCP and NAT
- ACLs, LAN security and VPN/tunnelling concepts
